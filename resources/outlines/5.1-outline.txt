- REST API or RESTful API (Representational State Transfer API )
    A REST API (Representational State Transfer Application Programming Interface) is an application programming interface that follows the principles of the REST architectural style to enable communication between client and server applications over HTTP.

A REST API represents data as resources, which are identified by URLs (Uniform Resource Locators) and manipulated using standard HTTP methods such as GET, POST, PUT, PATCH, and DELETE. Responses are commonly exchanged in formats such as JSON.

A REST API is an HTTP-based interface that allows clients to access and manipulate server-side resources according to the principles of REST.

REST API Rules
--------------
1. follow client - server architecture
2. respect all http methods (GET, POST, PATCH, DELETE, PUT)

METHOD ENDPOINT
GET /users  - fetch/get all users and return
POST /user  - handle create a new user
PATCH /user/1 - update one or more fields of a certain user 1
PUT /user/2 - update user 2 completely
DELETE /user/3 - delete user 3

instead of using POST /createUser, POST /updateUser


GET /users - html
GET /api/users - json
