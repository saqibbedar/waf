event module - work with events in NodeJs
    event - is an action or an occurrence that we can respond to
    can dispatch / enroll / register our own custom events and respond
    EventEmitter is a core module to create and handle custom events
	part of event module often used for building event driven systems in NodeJS
	key methods
		1. emit(eventName, [args])
			emits (or triggers) an event with a specified event name.
			pass arguments used by the listeners
			like calling a function - triggers all listeners attached to the specified event
		2. on(eventNAME, listener)
			attaches a listener (a function) to a specific eventName.
			listener will execute when the event is emitted
code example 
Create a program using NodeJS that listens for multiple events. 
Tracks the number of times each event is emitted.
logs a summary report of all event occurrences.
    create at least four or five events
    emit these events multiple times with different arguments
