# WAF (CS457): Web Application Frameworks

> WIP: Work in Progress!

This repository hosts coding examples, tasks, assignments, projects and much more written in `Node.js` and may be frontend code at some extent. But, it is mostly backend based. This repo will include all lessons and learnings that I will complete through out the course in WAF.

The contents and overall repository structure will keep changing until the course is finished.

# Getting Started

1. For this repo, and clone your forked repository:

    ```bash
    git clone https://github.com/<your-github-username>/waf.git && cd waf
    ```
2. Create a feature branch and push your changes and open PR and wait for approval.
3. If it really resolve any issue in our code or support documentation then it will merged to `main` branch.

> Note: Contribution guidelines will be added very soon!
